# Third-party and original assets

This file exists so nobody has to guess where the art, audio and code came from. It is deliberately
honest: if the provenance of a file is not documented in the repository, that is stated here.

redistributed as source in this folder.

## 3D models (`web/models/`, `models/`)

`sports.glb`, `toyota.glb`, `white-corolla.glb`, `yellow-car.glb`

These `.glb` files were supplied with the project and shipped in this build. **Their original author and
licence are not documented anywhere in this repository.** Before any commercial release, replace them or
record their licence here (source, author, licence name, link). If a model cannot be licensed, the game
falls back to its own procedural car meshes (`web/js/models.js`), so the game does not depend on them for
the physics or the HUD.

## Audio

There are no audio files in this project. Every sound — engine, tyres, collisions, nitros, rain, wind,
music loop, countdown beeps, victory/defeat jingles and all four horn voices (standard, sport, air horn,
melody) — is synthesised at runtime with the Web Audio API in `web/js/game.js`, `web/js/extras.js` and
`web/js/horn.js`. Nothing is sampled, so nothing needs an external music or SFX licence.

## Fonts

No font files are bundled; the UI uses the system font stack defined in `web/css/style.css`.
